# Academic Research Portfolio

A responsive, multi-page academic website starter for a researcher working across quantum optics, nanophotonics, spintronics, computational physics and biomedical optoelectronics.

## Pages
- Home
- About
- Research
- Projects
- Prototypes
- Publications
- Teaching
- Contact

## Personalize before publishing
1. Replace `YOUR NAME` and `Your Name` throughout the HTML.
2. Update the email address and profile links on `contact.html`.
3. Replace placeholder project descriptions with verified summaries of your work.
4. Add a current CV PDF under `assets/files/` and update its link.
5. Add only approved prototype photographs; confirm collaborator consent, institutional policy and IP permissions.
6. Update publication entries and distinguish published, submitted, preprint and in-preparation work.
7. Check every link and test on mobile and desktop.

## Preview locally
Open `index.html` in a browser, or run a local server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository for the public website.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select the deployment source (usually the main branch and root folder).
4. Follow GitHub's custom-domain instructions if using your own domain.
5. Enable HTTPS after DNS configuration has completed.

## Public website vs private research archive
Treat this repository as public. Do not upload confidential data, unpublished manuscripts you are not ready to disclose, private collaborator material, credentials, or sensitive research records. A hidden page, obscure URL, `noindex` tag or JavaScript password prompt is not access control.

Keep private material in a separate private repository or institution-approved encrypted storage, with multifactor authentication and independent backups. Check institutional data-management and IP rules before storing research data in any cloud service.
